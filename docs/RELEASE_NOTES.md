## Dialed 1.1.0

**Install:** download **`Dialed.dmg`**, open it and drag **Dialed** to Applications. The first time, right-click Dialed → **Open** (the app isn't notarized).

> Coming from 1.0.x? Install this version once by hand — from 1.1.0 on, Dialed updates itself.

### What's new
- **Automatic updates.** Dialed checks for new versions once a day and installs them for you (Settings → General → Updates). Every update is signed, so Dialed only installs versions published by its developer.
- **Smoother app.** Idle CPU use dropped from about 20% to about 1%; the menu bar icon and windows no longer redraw constantly.
- **Presses stay with Dialed** even while your music app is paused (before, a paused YouTube Music could keep the buds' presses).
- **New About page** with a "Made with ♥ by Taqi Saeed" card, quick links and Check for Updates.
- Clearer hints about holds: hold (noise cancellation) and press-then-hold (dial lock) are handled inside the buds and never reach the Mac.

### Known limitations
- Press-and-hold never reaches macOS.
- macOS shows its own volume indicator on each click (no public API hides it).
- Dialed appears under Now Playing while it's on (macOS only sends the buds' presses to that app).
- Unsigned build: macOS may ask for Accessibility again after an update.
